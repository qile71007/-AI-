🔒 私密配置功能 — 完整用户使用教程

一、功能简介

本功能让你可以将私密影视源（名称、播放地址、自定义关键词）全部加密后存储，只有本定制版 APP 才能解密使用。即使别人拿到你的配置文件，也看不到任何有效信息。

核心特性 说明

密文存储 配置文件中只保存加密字符串，无任何明文信息

原版兼容 原版 TV‑Box 因缺少 url 字段，自动跳过私密条目

解锁可见 输入口令后，私密源名称前显示 🔒 标识
自动上锁 退出 APP 后自动隐藏私密源

独立生成 支持手机 APP 内生成或电脑端离线生成

二、准备工作

你需要准备的三项信息

项目 说明 示例
源名称 私密源的显示名称 我的私人影视
播放地址 影视接口的真实 URL https://example.com/api.json
自定义关键词 你设定的私密关键词（自己记住） 123456 或 mykey

三、生成私密配置（二选一）

方式一：手机 APP 内生成（推荐⭐）

步骤 操作

1️⃣ 打开 APP，进入 设置 页面

2️⃣ 长按版本号（页面下方的版本信息文字，如 v1.0.0），弹出“私密配置生成工具”弹窗

3️⃣ 依次填写三项内容：源名称、播放地址、自定义关键词

4️⃣ 点击 “生成私密配置JSON” 按钮，下方会显示加密后的 JSON 结果

5️⃣ 点击 “复制JSON文本”，将加密内容复制到剪贴板

✅ 提示：复制成功后，弹窗会提示“JSON已复制到剪贴板”。

方式二：电脑端离线生成（备选）

步骤 操作

1️⃣ 在电脑上打开 smpz.html 文件（浏览器运行）

2️⃣ 输入 源名称、播放地址、自定义关键词

3️⃣ 点击 “生成JSON”，下方显示加密结果

4️⃣ 点击 “复制”，复制加密后的 JSON 字符串

四、将私密配置添加到配置文件中

步骤说明

步骤 操作

1️⃣ 找到你的配置文件（通常是网络上的 JSON 文件，或本地 tv.json）

2️⃣ 在 urls 数组中，新增一个对象，将刚才复制的加密内容粘贴进去

3️⃣ 重要：私密条目只能包含 enc_name、enc_url、enc_keyword 三个字段，不能有 name 或 url 字段

完整配置文件示例

```json
{
    "urls": [
        {
            "name": "公共影视源",
            "url": "https://example.com/public.json"
        },
        {
            "enc_name": "m564+ULZ0Uyt1ASWWQXacA==",
            "enc_url": "0cZV6O1ghXpPOC2aSW5H+kxT0VQQaTvb6rUPWj5AID/v2Ho9kPSeXAJjcRqmp97vWGLTUTzSuusM6MyF/8iQFA==",
            "enc_keyword": "8qwZ20QkAUJetuBUgnJ+fQ=="
        }
    ]
}
```

⚠️ 注意：urls 数组中可以同时包含公共源（name+url）和私密源（enc_name+enc_url+enc_keyword），两者互不干扰。

步骤 操作

操作步骤

步骤 操作

方式三 （如设置过锁定按钮）点击锁定按钮

✅ 提示：退出 APP 后自动上锁，无需手动操作，下次打开 APP 私密源默认不可见。

八、私密配置安全优势

安全特性 说明

✅ 密文存储 配置文件中源名称、播放地址、关键词全部加密

✅ 原版跳过 原版 TV‑Box 因缺少 url 字段，无法读取私密条目

✅ 专属解密 只有定制版 APP 才能解密使用

✅ 容错保护 解密失败自动跳过条目，不会造成 APP 闪退

✅ 退出上锁 APP 退出后自动隐藏私密源，防止他人查看

✅ 独立共存 公共源和私密源相互独立，原有功能完全不受影响

九、常见问题（FAQ）

Q1：输入解锁口令后，私密源没有出现？

· 检查是否已导入包含私密条目的配置文件
· 确认私密条目中三个加密字段（enc_name、enc_url、enc_keyword）完整
· 重新输入口令

Q2：私密源名称显示为乱码或空？

· 说明解密失败，请检查加密密钥是否与 APP 一致
· 建议使用 APP 内的生成工具重新生成

Q3：原版 TV‑Box 能看到我的私密源吗？

· 不能。原版 TV‑Box 解析时只识别 name 和 url 字段，私密条目没有 url 字段会被自动跳过。

Q4：我想更换私密源的解密关键词怎么办？

· 在 APP 内重新生成配置，使用新的关键词加密，替换配置文件中的旧条目即可。

Q5：别人拿到我的配置文件能解密吗？

· 不能。只有定制版 APP 内置了正确的 AES 密钥才能解密，外部工具无法破解。
