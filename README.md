第一步：申请并配置 API Key

选择想使用的模型，点击对话框中"免费申请"按钮，跳转官网注册并获取Key。

打开 TVBox → 设置 → 点击"AI助手"按钮。

顶部显示当前模型（默认豆包火山方舟）。

若未配置Key，自动弹出"配置 API Key"卡片。

粘贴Key到输入框，点击"保存 Key"即可。

第二步：使用AI助手

随机推荐配置 输入 "推荐配置" 随机显示5个配置名称和链接，提示回复数字1-5选择

数字选择配置 回复 1-5 选中对应配置，自动启用"添加此配置"按钮

智能搜索配置 输入需求描述（如"推荐一个稳定的点播配置"） AI理解需求并推荐配置，自动提取链接

直接粘贴链接 输入配置链接（如网页链接） AI自动识别并启用"添加此配置"按钮

切换模型 点击顶部"更换模型"区域，选择其他模型 自动切换，

再次输入key，点击右上角的key密钥，若未配置Key则弹出设置卡片

第三步：添加配置

当检测到有效配置链接时，底部"✅ 添加此配置"按钮亮起。

点击按钮 → 配置自动发送到TVBox。

TVBox后台加载配置 → 加载成功后对话框自动关闭。

在首页"线路"或"接口"切换里可看到新配置。
